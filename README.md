# UseIt

UseIt is a secure mobile gift-card wallet for scanning, organizing, and tracking user-authorized, closed-loop retailer gift cards.

## Senior Design MVP

- Scan barcodes and QR codes, with manual entry when scanning fails.
- Store card information securely and reveal sensitive details only on demand.
- Organize cards with search, filters, favorites, and folders.
- Track balances manually and provide official retailer balance-page links.
- Demonstrate one authorized balance-verification integration or sandbox flow.

The prototype does **not** issue, sell, load, transfer, redeem, or process gift-card funds. It excludes network-branded prepaid cards and unauthorized retailer-site scraping.

## Security

Never commit real gift-card numbers, PINs, screenshots containing them, API keys, or production configuration. Use synthetic, sandbox, expired, or zero-balance test cards only.
